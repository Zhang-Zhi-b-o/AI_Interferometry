## 当前状态（2026-10-19 收尾）

v2 已成为默认入口：`python run.py` 启动 PySide6 版（旧 Tkinter 仍可从 `src.ui.run_app` 回退）。
七页、助手九工具、寻中闭环、3D、标定、离线演示与电机连接入口均可用；
助手支持逐 token 流式，`michelson tools` 输出与助手注册表一致。
剩余：真机走查（相机/模型/OCR、方向映射、转停节拍、物理急停）与主流程点击数实测。

## 已确认决策

- PySide6 / Qt；固定七页：实时、搜索、条纹、读数、计算、厚度分布、助手。
- 复用现有领域算法、硬件封装；助手复用 `src.agent.provider.DeepSeekProvider` 和
  `src.agent.knowledge.KnowledgeBase`，不重新选型。
- 保留相对/标定双模式和标定采集；停用录像、回程差、激光引导、主动建议等，详见计划。
- 既有未提交源码、报告与数据保持原状，不混入自动提交。
