# 白光干涉测量工作台

可独立复制、安装和运行的新版 PySide6 程序。只需要本目录；旧版 `src/`、项目根配置、实验数据集及其他目录均不参与运行。

## 玻璃片自动找垂直

打开干涉相机并加载条纹模型，在「③ 确定条纹位置」顶部选择“最左为极限”或“最右为极限”，点击“开始 / 重置极限”即可。

程序实时维护中心条纹位置集合（最近 120 秒、最多 8192 个有效位置），从有至少三个邻近观测支持的位置中选择最左/最右参考。孤立极值不作为参考；建立连续轨迹后，明显偏离上一位置的跳点先排除，连续跳到别的条纹不会自动锁成新极限。真实画面中断或定位丢失后可重新定位。界面显示集合大小和排除的跳点数量。当前中心连续三个新鲜观测落在可信参考的允许误差内时，提示“已到当前最左/最右极限”。到位允许误差默认 ±15 px，可随时调整。离开范围、识别失败或超过一秒没有新画面时，撤销到位提示。

不分采集、结束采集和矫正步骤，不要求往返次数，不保存图像或本功能的时间线记录；位置集合仅存于内存，过期位置自动移除。运行时间不受帧缓存大小限制。后台识别使用最新帧，忙时不积压图像，因此过快经过或模糊的瞬间仍可能未被识别。

运行中切换左右方向会清除旧极限并立即按新方向继续寻找；点击“开始 / 重置极限”可清除本次极限重新寻找，点击“停止”结束。画面尺寸、ROI 或自动运动状态改变后需重新开始。

参考表示最近有效位置集合中有多帧支持的极限，不代表已经覆盖全部旋转范围，也不输出角度。位置连续性和邻域支持只能过滤部分误识别，无法单靠坐标证明条纹身份；实际垂直位置需结合光路判断。

## 下载后直接使用（推荐）

Windows 10/11、64 位：到 [GitHub Releases](https://github.com/Zhang-Zhi-b-o/AI_Interferometry/releases/latest) 下载 **AI_Interferometry_Windows_x64.zip**，完整解压到可写目录，再双击根目录的 `start.bat`。不要在压缩包预览窗口里运行。便携包已包含 Python、CPU 依赖、YOLO/OCR/钠灯模型及微分表驱动文件，无需安装 Python、CUDA，也无需运行 pip。

没有连接仪器时双击 `demo.bat`，可体验界面、虚拟电机、读数和离线助手。正式在线聊天需要用户自行填写 API Key；设备测量不依赖 API Key。

源码包与便携包不同：GitHub 的 Code → Download ZIP 只含源码，不含 Python 运行时。源码用户先安装 64 位 Python 3.10/3.11，然后双击 `app/start.bat`，首次会联网安装依赖；之后直接双击启动。更新源码后运行 `app/setup.bat`。也可执行：

```powershell
cd app
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe run.py --demo
```

便携版默认使用 CPU，适合没有独立显卡的电脑；GPU 环境的开发者可以自行安装匹配的 CUDA 版 PyTorch。运行目录请保留写入权限，日志和测量记录保存在 `app/logs`、`app/exports`。

## 功能与设备

- 实时相机预览、画面校正、ROI、单帧/连续 YOLO 识别、图片与录像保存。
- 条纹中心、角度、宽度、间距分析与位置记录。
- 电机手动控制、自动寻中和目标读数。
- 微分头信号直接读取与键盘拦截、自动记录，也保留第二相机 OCR 读数。
- 厚度计算、不确定度和多轮统计；钠灯拍频双端测量及平均波长自动计算。
- 本地知识检索、在线助手、原文出处、Word 测量报告和性能评测报告。

实测需要兼容的干涉仪相机、拍摄微分表的第二相机，以及使用现有串口协议的电机控制器。默认主相机编号 1、读数相机编号 0，可在界面调整。自动运动前核对电机方向、行程及停止功能；`Esc` 请求停止运动。

使用 C216:010B 微分头时，先停止独立采集工具，再在「④ 读数」点击「开始信号读取与拦截」，然后开启仪器连续传输。程序按硬件 ID 自动寻找当前 USB 设备；换接口后若缺少设备专属配置，或系统驱动文件缺失，会自动请求 Windows 管理员确认并完成配置，再继续连接。已配置的接口无需重复安装。连接失败原因会保留在信号状态栏，配置日志位于 `app/logs/signal-setup.log`。选择仪器实际单位（默认 mm），信号值统一换算为 mm，直接作为现有计算和定位使用的微分表读数，无需第二相机。默认自动加入读数历史及会话记录，可取消「自动记录每条信号」。信号有传输延迟，界面显示的是距电脑上次接收的时间，不是已测得的仪器延迟。停止读数或退出程序会释放拦截。

`models/` 已包含全量 2954 张默认 YOLO 权重、人工确认 600 张备选权重、历史权重及 OCR 的识别/检测/分类权重。内置模型无需另行下载。来源见 `models/MODEL_SOURCES.md` 和 `models/micrometer/SOURCE.md`。

## 配置与助手

程序从本目录读取资源，不依赖启动命令所在目录。配置优先级：`config.v2.yaml` → `config/video_demo.yaml` 设备预设 → 本目录 `config.yaml` 用户覆盖。可复制 `config.example.yaml` 为 `config.yaml`，填写需要覆盖的项目；相对模型路径以本目录为基准。

进入「⑥ 实验助手」→「API 设置」，填写自己的 API Key，默认 API 地址为 `https://api.deepseek.com`，模型为 `deepseek-chat`，保存后下一轮对话立即生效。密钥保存在本机 `app/config/secrets.yaml`，不会上传到仓库，发行包不包含任何可用密钥。

高级用户也可在启动程序的 PowerShell 中设置：

```powershell
$env:DEEPSEEK_API_KEY = "填入你自己的密钥"
.\.venv\Scripts\python.exe run.py
```

也可在本目录的 `config/secrets.yaml` 设置 `deepseek_api_key`，此文件被 Git 忽略。默认接口为 `https://api.deepseek.com`，模型为 `deepseek-chat`。图像复核需在 `config.yaml` 的 `agent.llm.models.vision` 设置接口支持的视觉模型。请求费用由所用服务收取。

离线助手可设置 `agent.chat_mode: local` 或使用 `--demo`。正常在线模式缺少密钥或网络时提示错误；设备测量和本地报告可独立使用。

## 钠灯拍频双端测量与平均波长

在「实时画面」打开干涉相机、「搜索条纹」连接电机、「读数」启动有效微分表读数，然后进入「⑦ 钠灯拍频」。方向选择正转/反转，默认10档（最慢）。点击“开始双端测量”即授权本次程序自动运动。无需替换原白光模型，钠灯权重独立内置在models/sodium/best.pt。

先将光路停在目标第一端附近；程序等待连续3个新帧且持续至少0.25秒识别为端部，发停车请求，确认停止指令写入后等待至少0.3秒及新的有效微分表读数，记录第一端。随后按所选方向单向转动，必须完整经过“离开第一端的清晰状态→中间模糊→再次清晰”才会接受下一次端部检测。中间模糊不会触发测量停车，同时出现可靠中间检测与端部检测时，中间类别优先否决停车。另一端确认后先停车，再等待停车后新读数并记录。页面展示三位小数的两端微分表读数及有符号差值（mm），并自动显示钠双线平均波长（nm）；界面不展示公式或不确定度。

固定计算模型：两端之间含一次中间模糊，跨两个可见度周期；沿用本项目微分表示值与镜面位移20∶1的传动比，给定钠双线间隔0.6 nm，采用近双线近似 `平均波长(nm) = sqrt(30000 × abs(d₂-d₁)(mm))`。依据 [LEOI-19 仪器实验说明 §5.1.5](https://lambdasys.com/uploads/info/LEOI-19-Content.pdf) 的可见度周期关系。结果依赖固定谱线间隔与端点识别，并非独立测得两条谱线的各自波长；传动比和端点识别仍需实机核实。原始读数、固定常数、周期数和结果一并存入测量事件，不对原始读数预先取三位小数后再计算。未完成或读数差为零时不显示平均波长。

使用实际相机画面作为输入；必要时先Shift框选与训练视野接近的有效光斑区域。运行中修改ROI、相机尺寸变化、相机失联、读数超过1.5秒无更新、识别超过1.5秒无新结果、超过最长运行时间或人工急停，都会中止并请求停车。若中间状态未被识别，不会跳过顺序直接接受终点；用户可随时点击停止或按Esc。电机/读数设备连接及识别线程异常会反馈在本页面和日志。

停止确认表示串口指令成功写入，并非独立编码器确认机械停稳；0.3秒等待及新读数规则未补偿仪器传输延迟。两个读数和参数自动写入当前exports/sessions会话的sodium_two_end_measurement事件。关闭程序、助手停止和手动电机操作均能停止此闭环，和寻中/目标读数互斥。演示模式不执行钠灯闭环（合成白光画面不代表钠灯）。首次真实测量仍需检查光路、方向和现场停止响应。

## 微分表连接与排查

1. 支持的直接信号设备是 USB HID `VID_C216&PID_010B`。先插入微分表，关闭独立采集工具，再到「④ 读数」选择正确的信号单位，点击“开始信号读取与拦截”。
2. 首次连接会在必要时弹出 Windows 管理员确认，只为该微分表配置过滤驱动；不会自动安装全局键鼠过滤器。驱动文件与许可证已内置。若提示需要重启 Windows，请重启后再试；系统阻止旧驱动时不要关闭系统安全功能，可改用相机 OCR。
3. 开启仪器的连续传输。程序拦截该设备的键盘输入并转换为三位小数的 mm 读数；停止读取或退出程序后恢复该设备正常输入。
4. 其他型号仪器不保证兼容直接信号模式，可使用第二相机拍摄 LCD，通过内置 OCR 模型读数。相机序号需与主相机不同。
5. 如需撤销该设备的过滤配置，先停止读取，使用便携包的“remove-micrometer-filter.bat”，或以管理员身份执行 `runtime\python.exe -X utf8 app\engine\hardware\signal_setup.py --remove --log`。源码用户将解释器路径换为 `.venv\Scripts\python.exe`。按提示重新插拔仪器或重启。

## 电机连接

在「② 搜索条纹」中刷新串口，选择 CH340 等控制器对应的 COM 口（也可填 auto），默认波特率9600。首次连接前核对仪器的实际协议；本程序使用 `R/r/S/D/+/-/?`，不兼容的控制器不能直接驱动。连接后先用“手动电机控制 → 查询状态”验证通信，再核对方向和行程后使用自动运动。显示“已连接”只说明串口已打开；查询无回复时检查控制板供电、USB/串口线和固件协议，不能认为电机已经执行指令。

## 发布构建与第三方组件

便携包采用 uv / Astral python-build-standalone 的可移动 Python 运行时，不引用开发机器的 Python 或虚拟环境。构建需要 Python 3.11+ 和 uv：`python app/distribution/build_portable.py --output <新输出目录>`。构建完成后可在另一目录解压验证，依赖版本见 `DEPENDENCIES.txt`，应用资源校验见 `MANIFEST.json`，压缩包校验见同名 `.sha256`。

第三方组件保留原有许可证：微分表 Interception 驱动见 `engine/hardware/vendor/`，Python 运行时及各依赖许可证见便携包 `runtime/`。模型与 OCR 来源见 `models/`。构建过程不会连接或操作仪器；软件模拟验证不等于实际计量校准。
