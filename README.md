# AI Interferometry

迈克尔逊白光干涉实验智能辅助系统。程序使用 USB 相机采集干涉图像，通过双类别
YOLOv8 模型识别零级条纹和近场条纹，在检测框内进一步定位中心条纹，并通过 RS-232
控制步进电机完成自动搜索和闭环寻中。第二台相机可读取数显微分表；系统还提供视频
录制、玻璃片厚度多轮测量与统计、临时位移控制、回程差测量、中心条纹宽度分析、实时
测量记录，以及一个**可自主执行工具的实验助手智能体**（既能逐轮互动引导，也能自定
计划、调用工具完成测量与控制，并给出 DeepSeek 主动建议）。纯逻辑测量与分析还可通过
`michelson` 命令行在终端独立运行。

> 快速定位：本文档的「[快速上手：完整实验流程](#快速上手完整实验流程)」给出从头
> 到尾的每一步操作；「[实验助手使用指南](#实验助手使用指南)」单独详述 AI 助手的
> 用法。

## 当前版本

- 主分支：`main`
- 当前模型：`models/current/best.pt`（`yolov8n_all_human_confirmed`，来源和历史见
  `models/MODEL_SOURCES.md`）
- 模型类别：`0 = zero_order`，`1 = near_fringe`
- 默认推理：`imgsz=640`、候选 `conf=0.25`、模型 NMS `iou=0.70`、优先 CUDA
- 默认自动寻中：已知方向单向搜索，搜索档位 9，模糊安全档位 10
- Python：3.10 或更高版本

当前模型由合并后的全部人工确认数据训练，最佳权重位于第 110 轮，验证结果如下：

| Precision | Recall | mAP50 | mAP50-95 |
| ---: | ---: | ---: | ---: |
| 0.896 | 0.910 | 0.951 | 0.774 |

验证集的最佳综合 F1 约为 `0.91`，对应置信度约 `0.50`。上一版
`pre_annotation_yolov8n_pool_after_1240_best` 已归档到 `models/history/`。

### 统一检测筛选策略

模型以 `0.25` 输出候选，再由 `src/vision/detection_strategy.py` 统一筛选。实时画框、
中心定位、近场路标、时序融合和自动寻中全部使用筛选结果。

- `≥0.60` 为高可靠框；`0.50～0.60` 接受并标记复核；`0.30～0.50` 只有与最近
  两帧中的同类可靠框匹配才保留。实时模式只使用已经到达的历史帧，不凭空补框；
- 取消旧模型的固定中心与固定宽高范围，只删除越界、非有限值、边长小于图像
  `0.015` 或面积小于整图 `0.003` 的明显非法框，因此允许多视场和接近全图的大框；
- 同类框按置信度排序，IoU `≥0.65` 或小框覆盖率 `≥0.80` 时只保留最高置信度者；
  `zero_order` 最多 2 个，`near_fringe` 最多 4 个；
- 跨类别 IoU `<0.75` 时都保留；达到 `0.75` 后，仅在置信度差至少 `0.15` 时删除
  较低者，否则都保留并标记复核；
- 两个黑框、3～4 个彩框、时序挽救、跨类别高度重合、超出数量上限，以及空结果中
  存在未确认弱框时，策略结果都会携带 `needs_review` 和具体原因。

这套阈值保持 `0.50` 的常规精度，同时用 `0.30` 的时序挽救下限减轻运动模糊和偶发
漏检，偏向保证条纹能连续识别；弱框不会无限续接，只能由最近可靠帧提供依据。

## 主要功能

- 干涉相机实时预览、旋转、缩放、平移、ROI 和视频录制；
- YOLO 实时检测 `zero_order` 与 `near_fringe`；
- 在零级检测框的扩展区域内定位实际中心条纹，不把框中心直接作为结果；
- YOLO 短时漏检时，在上一帧区域内继续视觉跟踪中心；
- 识别倾斜、弯曲、变色和低对比度条纹，使用历史轨迹跨越短时漏检；
- 根据连续位置估计条纹移动方向、位移和速度；
- 针对电机运动模糊自动降低速度，清晰画面恢复后再恢复正常控制；
- 搜索方向与识别节拍独立选择，可组成四种自动寻中方式；
- 使用第二台相机和本地 PP-OCRv6 ONNX 模型读取数显微分表；
- 玻璃片厚度多轮测量与统计（手动输入 / 从已记录读数导入，均值、标准差、极值）；
- 支持目标读数控制、回程差测量、中心条纹宽度分析、实时测量记录、原始/标注视频录制；
- 使用本地知识库和 DeepSeek 提供**逐轮互动**的实验操作、计算与报告辅助；
- 实验助手可切换为**自主执行智能体**：自定计划、逐步调用工具（读表、查状态、测条纹、
  算厚度/误差，或经人工确认后驱动电机），界面实时展示计划与工具调用过程；
- 无操作一段时间后，DeepSeek 自动分析当前状态，给出「现状 + 下一步 + 其他建议」的
  主动提示（省 token 的短答 + 空闲触发，离线时回退本地确定性提示）；
- 提供 `michelson` 命令行，纯逻辑子命令（算厚度、评不确定度、析条纹宽度、估单帧厚度
  分布、寻中状态机、列出工具注册表）可脱离 GUI 运行；
- 提供单张彩色干涉图的相对厚度分布分析工具。

YOLO 输入、录像原始帧或中心定位计算。

## 快速上手：完整实验流程

下面按固定实验流程给出每一步在界面上的具体操作。**「04 实验助手」可在任意一步
打开**，它会读取实时状态，逐轮提示你当前该做什么、看什么；开启「自主执行」后，
也可以直接下达「调出中心条纹并测量条纹宽度」这类任务，让它自定计划并调用工具
（涉及电机动作的工具会先弹确认框）。

1. **打开激光光源，调出非定域干涉条纹。**
   先在光路上目视调整，不需要打开软件。可在「04 实验助手」点「预习指导」先了解
   原理与预期现象，或点「调出条纹」让它带你逐步确认现象。

2. **加上毛玻璃，慢慢调至等厚干涉。** 移动动镜接近等光程位置，以条纹接近直线
   为观察标志。若不确定，可在助手对话栏描述「加毛玻璃后条纹还是散的」，让助手
   帮你判断如何纠偏。

3. **调节动镜水平倾角，得到约 1 mm 厚的等厚直条纹。** 目视确认条纹变直变密。

4. **换上白光扩展光源并打开摄像头。**
   - 展开「01 视觉观察 → 摄像头控制」，选择相机索引后点「打开」；
   - 用画面上的旋转/缩放/平移把干涉镜面移到视野中央，需要时可调整 ROI；
   - 展开「03 测量记录 → 视觉微分表读数」，选第二相机索引并启动读数。

5. **加载模型、开始预测，并自动寻找中心条纹。**
   - 「01 视觉观察 → 模型与预测」：加载 `models/current/best.pt`，点「开始预测」；
   - 「02 运动控制 → 电机控制」：连接电机，先用「+ / − / S / R / r」确认物理方向
     和停止命令；
   - 「02 运动控制 → 自动寻找中心条纹」：选择搜索方向与识别方式，点启动；
   - 当中心黑条纹被识别并稳定在画面中央时，自动寻中自动停止。

6. **多次测量并记录数据。**
   - 玻璃片厚度：见「[玻璃片厚度测量与多轮统计](#玻璃片厚度测量与多轮统计)」；
   - 中心条纹宽度：见「[中心条纹宽度测量](#中心条纹宽度测量)」；
   - 微分表读数 + 中心条纹宽度同步记录：见「[实时测量与记录](#实时测量与记录)」。

7. **计算误差与不确定度，生成报告。** 回到「04 实验助手」，点「误差计算」或
   「生成报告」。助手会用程序算好的均值、标准差、不确定度和异常值检验直接生成
   数据表格与报告（数值以程序为准，不会凭空编造）。

完成实验后，依次停止自动寻中、预测、录像和读数，最后关闭相机。

## 实验助手使用指南

实验助手是本系统体现 AI 价值的核心。它有两种工作方式，可在同一浮窗里切换：

- **互动引导（默认问答）**：像搭档一样逐轮引导，根据实时状态给出「AI 洞察」；
- **自主执行智能体**：开启「自主执行」后，模型自定计划、逐步调用工具执行任务
  （读表、查状态、测条纹、算厚度/误差，或经人工确认后驱动电机）。

入口有两处，功能不同、不要混淆：

- **「03 测量记录 → 实验助手 · 多轮测量与统计」**：玻璃片厚度多轮测量的数据表格
  与统计（均值、标准差、极值），见下一节；
- **「04 实验助手 → 实验助手」**：AI 对话助手（浮窗），负责预习、过程指导、条纹
  分析、误差计算、报告与自主执行，本节所述。

### 打开与界面

在「04 实验助手」模块点「打开助手」，浮窗出现后可拖动、缩放、收回，不遮挡设备
操作。浮窗分四个可折叠区域：

| 区域 | 作用 |
| --- | --- |
| 状态栏 | 连接状态、实验进度条、下一步提示、**AI 洞察**、**主动建议**、智能体执行控件、计划与工具活动流 |
| 快捷指令栏 | 五个「引导流程」入口按钮 |
| 对话栏 | 多轮对话与可点选项 |
| 输入栏 | 自由输入 + 选项按钮行 |

右上角「连接」测试 DeepSeek 是否在线；`A− / A / A+` 调整字号。状态栏顶部另有
「智能体执行」控件组：**自主执行**开关、**仅规划**开关和醒目的**急停**按钮。当
智能体请求电机动作时，浮窗顶部会弹出「确认执行 / 拒绝」的运动确认行；确认超时
视为拒绝。

### 自主执行模式（智能体）

开启「自主执行」后，助手不再只是回一段文字，而是像 OpenClaw 一样运行
「接收任务 → 制定计划 → 调用工具 → 观察结果 → 汇报」的循环：

- 你在输入栏下达任务（如「调出中心条纹并测量条纹宽度」），模型先用 `set_plan` 把
  计划写到状态栏，供你监督；
- 随后逐步调用工具。**只读工具**（`get_context` 查状态、`micrometer_read` 读表、
  `motor_status` 查电机、`fringe_width_analyze` 测条纹、`glass_thickness_calculate`
  算厚度、`uncertainty_analyze` 评不确定度、`experiment_session_stats` 查会话等）
  自动执行，无需打断；
- **运动工具**（`auto_center_start` 自动寻中、`measurement_start` 目标读数测量、
  `backlash_measure` 回程差测量）会先弹出确认行，你点「确认执行」才真正驱动电机；
  **停止工具**（`motor_emergency_stop` / 各 `*_stop`）始终放行，可随时急停；
- 每次工具调用的名称、参数与结果都会写入「工具活动」流，最终回答与工具结果一致，
  绝不编造读数或谎称已动电机。

勾选「仅规划」进入 dry-run：工具只返回占位结果、不真正执行，用于先看模型会如何
规划。单次任务最多调用 `agent.max_steps`（默认 12）轮工具，超限即停止并汇总。整套
智能体只编排「高层操作」（开/停自动寻中、目标读数测量、回程差测量、单帧分析），
低层 PID/寻中/停车确认仍由 GUI 现有的实时循环安全执行。

### 五个引导流程按钮

点一个按钮即发起对应引导，助手会按互动模式逐轮推进，而不是一次倒完：

| 按钮 | 用途 |
| --- | --- |
| 预习指导 | 目的、原理、仪器、关键公式、安全事项、预期现象，最后用自检问题考你 |
| 调出条纹 | 按四阶段带你调出白光干涉条纹，见下 |
| 过程辅助 | 读取实时状态与日志，判断你处于哪一步，只给当前一步并等你确认 |
| 误差计算 | 依据记录与数据做误差 / 不确定度计算，缺数据会明确列出缺项 |
| 生成报告 | 按固定结构生成实验报告，缺失内容标记「待补充」 |

「调出条纹」按最难的四阶段逐轮追问：① 激光下是否出现非定域条纹；② 加毛玻璃后
是否逼近等光程、条纹是否接近直线（等厚直条纹）；③ 换白光扩展光源后是否出现彩色
条纹；④ 是否出现中央黑色零级条纹。每阶段先问「你观察到什么」，再据此判断进入下一
阶段或纠偏。

### 互动引导模式

实验过程与「调出条纹」时，助手**一次只推进一步**：讲清当前操作、观察标志和一个
需要你确认的问题，等你回复后再给下一步或纠正。需要你选择时，回答末尾会出现一行
可点选项，例如：

```
【选项】看到条纹了；还没看到；条纹模糊不清
```

这些选项会渲染成输入框上方的一排按钮，点一下即作为反馈发出，无需打字。你也可以
在输入栏自由输入现象描述（如「条纹向左跑」）或提问，回车发送（`Ctrl+Enter` 也行）。

### AI 洞察

状态栏「AI 洞察」一行用确定性规则对实时状态给出即时诊断，例如「条纹尚未识别，
请完成第 2 步」「微分表读数已过期，请等待新读数」「中心条纹已稳定，可记录数据」。
它是规则先行、零调用、无幻觉的实时判断，帮助你快速知道「现在卡在哪」。

### 主动建议（DeepSeek 空闲分析）

状态栏「主动建议」一行在**无操作 / 状态稳定一段时间后**（默认 `suggestion_idle_seconds`
= 45 秒），才由 DeepSeek 分析当前状态，给出精简的「现状 + 下一步 + 最多两条其他
建议」；输出被限制在很短（`suggestion_max_tokens` = 200）。这样既让模型真正参与
判断，又用「空闲触发 + 精简上下文 + 短答」把 token 消耗压到很低。离线或调用失败时
自动回退为本地确定性提示（来源标注「本地提示」）。你正常操作时不会被打扰——只有
停下来一段时间才会出现。

### 误差、不确定度与报告的确定性计算

当你提出误差 / 不确定度 / 报告类请求时，程序会**先做确定性数值计算**（均值、
标准差、GUM 不确定度、Grubbs 异常值检验等），把结果以「程序已计算的确定性结果」
交给模型；模型必须直接引用这些数值，只负责解释测量模型、灵敏系数、误差来源与改进
建议，绝不自行重算或编造。报告遵循固定八段结构（目的 / 原理 / 仪器 / 步骤 / 原始
数据与现象 / 数据处理与误差 / 结果分析 / 结论）。

### 离线降级

未配置 DeepSeek 密钥时，助手自动用本地知识库回答，仍会基于实时状态给出「现场判断
→ 下一步 → 观察标志」。注意：**自主执行模式依赖 DeepSeek 的 function calling，离线时
不可用**，会自动退回纯文本引导；本地知识库问答与确定性计算不受影响。配置方法见
「[配置](#配置)」。

## 命令行工具（michelson）

与 GUI 智能体共用同一批纯逻辑能力的 `michelson` 命令行，可脱离 GUI 在终端运行
（`pyproject.toml` 已注册 `[project.scripts] michelson = "src.cli:main"`；未安装时
也可用 `python -m src.cli ...`）。硬件子命令（运动/急停/读实时表）需在 GUI 内运行，
CLI 不另建无头硬件连接。

```powershell
# 由两次微分表读数计算玻璃片厚度
michelson measure glass-thickness 1.000 1.500 --n 1.4586

# 玻璃片厚度不确定度评定（厚度序列，可选附带 d1/d2 读数）
michelson measure uncertainty 1.23 1.24 1.22 --d1 1.000 1.001 0.999 --d2 1.500 1.501 1.499

# 分析图像中心条纹宽度（自动规避中文路径）
michelson analyze fringe-width C:\path\to\fringe.jpg --center-x 640

# 单帧薄膜厚度分布估计
michelson analyze thickness-distribution C:\path\to\fringe.jpg `
  --wavelength 589.3 --refractive 1.523 --calibration calib.csv --baseline baseline.jpg

# 自动寻中状态机（纯模拟）
michelson control center-search --steps 10 --direction forward --mode bidirectional
```

## 玻璃片厚度测量与多轮统计

玻璃片厚度属于拓展实验：在动镜光路中加入折射率已知的薄片，通过条纹移动对应的
位移计算厚度。公式为

```text
h = (d2 − d1) / [10 × (n − 1)]
```

其中 `d1`、`d2` 是两次中心条纹分别出现时的微分表读数（单位 mm），`n` 为玻璃折射率
（默认 `n = 1.4586`）。

### 单次测量（「03 测量记录 → 玻璃片厚度测量」）

1. 在中心条纹第一次出现时点「记录当前微分表读数」，得到一条读数记录（形如
   `R1  1.234567 mm  时间戳`）；
2. 移动动镜使条纹再次出现，再点「记录当前微分表读数」得到第二条；
3. 在记录列表分别选中两次读数作为 `d1`、`d2`，点「用所选两次读数计算厚度」；
4. 若结果为负，核对或交换 `d1`、`d2` 的选择顺序。

### 多轮统计（「03 测量记录 → 实验助手 · 多轮测量与统计」）

1. 填写实验名称、操作者、样品编号；需要时改折射率 `n`（失焦后回车确认）；
2. 用两种方式之一添加测量轮次：
   - **手动输入**：直接填 `d1`、`d2`（可加备注），点「手动添加测量」；
   - **从记录导入**：点「刷新读数列表」，在「选择 d1 / 选择 d2」下拉里选两次已记录
     读数，点「从记录导入」；
3. 测量记录表格实时显示轮次、`d1`、`d2`、厚度、来源与备注；可删除所选或清空全部；
4. 「统计摘要」自动给出测量次数、平均值、标准差、最小值、最大值；
5. 「保存会话 / 加载会话」把整个多轮测量存为 JSON 文件，便于续做或存档。

这些记录与统计会同步进助手上下文，供「误差计算 / 生成报告」直接使用。

## 临时测量（模块 05）

### 目标读数控制

在「目标读数 (mm)」填入期望的微分表读数，点「开始旋转到目标读数」，程序按正转
（读数增大）/ 反转（读数减小）自动驱动电机逼近目标；点「停止」随时停车。默认约定
正转使读数增大、反转使读数减小，没有新鲜可信读数时立即停车等待，不会猜测方向。

### 回程差测量

在中心条纹对齐画面中心线时，分别标定起点与终点读数（可手填或点「标定」取当前
读数），点「开始回程差测量」。程序按单向越过端点的方式执行，避免端点附近反复换向
引入额外回程差；起点读数须小于终点，端点仅近似到达，过程不反向修正位置。

### 中心条纹宽度测量

1. 确保干涉画面已打开（有可分析的实时画面）；
2. 点「分析当前画面」，程序取横向亮度剖面、估计条纹周期、切分明暗条纹，并按中心
   条纹位置（默认画面中心，或自动寻中找到的 `_center_line_x`）给出该处条纹的宽度；
3. 结果区显示中心条纹类型（亮纹 / 暗纹）、中心 x、左右边界、宽度（px）、半高全宽
   （亮纹）与整体周期，以及识别到的条纹段数。

### 实时测量与记录

同时记录**微分表读数**与**中心条纹宽度**，并给每条数据命名：

1. 点「开始实时测量」，进入持续分析状态——微分表读数约每 0.5 s 刷新，中心条纹宽度
   约每 1 s 分析一次（宽度分析做了节流，避免卡顿）；
2. 在「数据名称」输入框给本条数据命名（留空则自动用「数据 N」）；
3. 点「记录当前数据」，当前微分表读数与中心条纹宽度作为一条记录写入下方列表；
4. 列表显示 `#序号  名称  微分表读数  宽度（类型）`；点「清空」删除全部记录；
5. 点「停止实时测量」结束持续分析（停止后读数显示清空，记录按钮禁用）。

## 自动寻找中心条纹

自动寻中的目标是把识别到的零级中心条纹移动到画面水平中心。YOLO 负责提供零级框
和近场路标，局部图像算法负责框内精确定位，时序跟踪负责平滑位置并处理短时漏检。

### 两组必选策略

界面将原来的三个互斥选项拆成两个独立选项组，每组必须选择一项：

1. **搜索方向**
   - 未知方向，双向寻找：以启动位置为虚拟零点，记录已搜索范围并交替扩展左右区域；
   - 已知方向，单向寻找：中心出现前始终沿人工选择的正转或反转方向搜索。

2. **识别方式**
   - 边转边识别（默认）：电机连续旋转，视觉系统持续识别并处理运动模糊；
   - 转一段，停下识别：定时转动、停车、等待画面稳定，再连续检查若干帧。

两组可自由组合，例如「未知方向 + 转停识别」会在双向扩展范围内分段转停，
「已知方向 + 转停识别」则始终沿指定方向分段搜索。转停方式只在停车稳定阶段接受中心
候选，避免运动模糊误判；中心候选确认期间保持停车。任何组合找到中心后都复用同一套
标准闭环完成居中。

双向方式会快速穿过已检查区域，连续可靠的 `near_fringe` 路标可平移搜索中心；
检测框抖动或单帧误检不会触发频繁换向。单向方式中的历史信息只用于保持方向和模糊
降速，确认中心后才允许为闭环居中而换向。

### 模糊、漏检与历史信息

视觉融合不只依赖单帧 YOLO。程序会分析二维局部纹理，以补偿条纹倾斜、弯曲、颜色
变化和模型偶发漏检；位置历史用于估计速度，并在短时运动模糊期间预测条纹位置。
历史预测不能单独触发换向或迁移搜索中心，只能保持运动连续并降低速度。

连续模糊或完全没有视觉证据达到设定帧数后，控制器进入安全慢速状态；连续获得清晰
证据后才退出。为了降低实时负载，YOLO 正常命中时默认每 3 帧更新一次纹理分析；
YOLO 漏检时仍逐帧分析，不降低补漏能力。

中心候选需要连续多帧确认。进入中心容差后电机立即停止，连续稳定达到设定帧数后才
判定完成。中心短时丢失会先保持或等待，持续丢失后才恢复搜索。自动控制同时具有最长
运行时间、串口失联和人工停止保护；这些软件保护不能替代机械限位。

- `yolo.fringe_texture_interval_frames`：YOLO 命中时的纹理分析间隔；

  `0.25` 和模型 NMS 阈值 `0.70`；
- `auto_center.direction_mode`：`single_direction` 或 `bidirectional`；
- `auto_center.recognition_mode`：`continuous` 或 `stop_and_detect`；

- `auto_center.blur_safe_gear`：模糊期间使用的安全档位；
- `auto_center.stop_detect_move_seconds`：转停模式每轮转动时间；
- `auto_center.stop_detect_settle_seconds`：停车后的画面稳定等待时间；
- `auto_center.stop_detect_frames`：停车后连续检测帧数。

## 微分表与临时测量
