# 条纹宽度分析

对白光干涉竖条纹图像做逐段分析，识别每一段条纹的：

| 属性 | 说明 |
|------|------|
| 位置 | 条纹横向中心坐标（像素） |
| 宽度 | 条纹横向跨度（相邻极值中点之间的边界宽），亮纹额外给出半高全宽 FWHM |
| 轮廓 | 条纹横截面的亮度剖面（逐像素灰度序列） |
| 颜色 | 条纹中心区域的代表性 RGB + 色相名（洋红/蓝/黄绿等） |

## 运行

```bash
python analyze_fringes.py [图片目录] [输出目录] [-n 张数]
```

- 默认读取 `20260811-0513-10.9599711-wan/images`，处理前 4 张有有效条纹的图。
- 每张图产出三样：`*_annotated.png`（原图 + 条纹边界/中心线/颜色块标注）、
  `*_profile.png`（亮度剖面图，逐段着色）、`report.json`（所有条纹的结构化数据）。

## 算法

核心是**只追踪亮纹的 2D 中心线，暗纹由相邻亮纹的中点推导**，从而对倾斜、
弯曲甚至扇形汇聚的条纹都能如实刻画轮廓。

1. 把图像沿竖直方向切成若干水平带，在每个带里用 `find_peaks` 找亮峰（只找亮纹，
   对比度高、稳定），并剔除贴边反光与暗背景里的噪声凸起。
2. 从峰最多的带（通常是零级条纹中段）出发，向上下用最近邻匹配把逐带亮峰连成
   2D 中心线——倾斜条纹得到斜线、弯曲/扇形条纹得到曲线，每条中心线即该亮纹的
   真实轮廓。
3. 暗纹是相邻亮纹之间的极值，取两条相邻亮纹中心线的逐点中点即暗纹中心线，
   无需在低对比度下独立找暗谷，也就不可能把黑背景误判成暗纹，且明暗天然交替。
4. 边界用相邻条纹中心的中点；首/末条纹只有内侧有邻居，外侧按内侧半宽镜像对称
   扩展（不拖到黑背景），避免最外侧亮纹宽度被背景撑大。
5. 每条纹沿中心线采样代表性颜色，并记录横截面亮度剖面（`contour`）与 2D 中心线
   （`centerline`），位置取中心线的平均 x。

OpenCV 在 Windows 下不认中文路径，脚本用 `np.fromfile + imdecode` 绕过。
