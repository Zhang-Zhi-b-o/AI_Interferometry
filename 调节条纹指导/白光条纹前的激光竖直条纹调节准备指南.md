# 白光条纹前的激光竖直条纹调节准备指南

## 1. 目的与完成状态

这一步不是用激光直接寻找白光零级条纹，而是先利用激光亮度高、相干长度长、容易观察的特点，把迈克尔逊干涉仪调到适合切换白光的初始状态：两臂返回光斑充分重合，扩束后出现清晰的等厚直条纹，条纹整体竖直、间距适中且画面稳定，并把动镜轴向位置带到预期的近等光程区域。

完成时应同时满足：

- 两路主要返回光斑在观察屏或相机画面中重合，不是只在一个位置“擦边相交”。
- 扩束后有连续、近似平直的激光条纹，条纹覆盖有效观察区。
- 条纹相对画面竖直方向的倾角足够小；本项目实时指导以绝对倾角不大于约 3° 作为“无需继续纠正方向”的判据。
- 条纹不过密到无法分辨，也不过疏到视场中只有一条；能清楚比较相邻条纹间距。
- 停手后条纹稳定，不存在持续漂移、明显振动、过曝或运动模糊。
- 已记录此时的动镜轴向读数和旋钮状态，供换白光后在附近小范围寻找彩色条纹。

激光相干长度长，因此“激光条纹清楚”本身不能证明两臂已经达到白光所需的零光程差。最终零光程差仍必须在换白光后，以出现彩色条纹并找到中央黑色零级条纹为准。

## 2. 当前装置的旋钮定义

以下方向只对当前装置有效，并且一律以实验者站在动镜背面、正对两个旋钮时观察为准。若从镜面正面观察，顺、逆时针会反转。

- 旋钮 A：动镜背面左上侧旋钮，主要用于改变条纹整体方向。新版说明记录：顺时针转 A 时镜面上方凸起、底座侧基本不动，形成上宽下窄的竖向楔角，镜面上方对应光程减小；逆时针变化相反，竖向楔角减小并可趋近于零。
- 旋钮 B：动镜背面右下侧旋钮，主要用于改变条纹疏密。新版说明记录：顺时针转 B 时镜面右侧凸起、左侧基本不动，形成左窄右宽的横向楔角，镜面右侧对应光程减小；逆时针变化相反，横向楔角减小并可趋近于零。
- A、B 都会同时影响方向和间距，不是完全独立的两个自由度。应采用单旋钮、小步、交替迭代，不能同时拧两个旋钮。

## 3. 安全和调节前检查

1. 激光光束只能投向屏幕或相机，不得直视激光器出口、分束器、镜面或任何镜面反射光；调整元件前先确认旁人不在光路中。
2. 检查激光器、分束器、补偿板、固定镜、动镜和观察屏是否牢固，光学面无明显灰尘和指印。不要在激光开启时把眼睛降到光轴高度找光斑。
3. 确认动镜轴向微分机构不在行程端，A、B 倾角旋钮没有顶死。任何旋钮阻力突然增大时立即停止。
4. 先关闭自动寻中或其他电机动作。人工调倾角期间一次只改变一个机构，避免无法判断哪项操作造成了条纹变化。
5. 初始对光时先不用扩束镜或毛玻璃，用小光斑更容易判断两路返回光的位置。多份大学实验讲义都采用“先重合两个返回光斑，再放入扩束元件观察条纹”的顺序。

## 4. 详细操作流程

### 阶段一：把入射激光调到正确高度和方向

1. 用白纸屏接光，不要用眼睛迎着光路观察。调整激光高度，使光束通过分束器有效区域，并尽量落在两块反射镜的中心附近。
2. 必要时暂时移开或转开分束器，先使激光正入射到直通臂镜面，并让返回光沿原路附近返回；再恢复分束器，使另一臂也被照亮。
3. 若光斑明显偏离镜面中心，优先移动激光器、分束器或仪器整体做粗调，不要用 A、B 承担大范围找光任务。

观察标志：两个干涉臂都有明亮的主要返回光斑，且光斑处在屏幕或相机的有效视场内。

### 阶段二：识别并重合两路主要返回光斑

1. 在输出端放置观察屏。分别短暂遮挡一条干涉臂，确认哪一个主要光斑来自固定镜、哪一个来自动镜；操作时不要触碰镜面。
2. 恢复两臂，用动镜倾角旋钮把两个主要光斑逐步靠近。若还有较弱的鬼像，只对准两路最亮、随相应镜面调节而移动的主光斑，不追逐分束器前后表面的弱反射。
3. 先在较近的屏位置重合，再把屏移远或在远处目标上检查。若远处又分开，说明两束光只有位置相交而传播方向尚未一致；应在近、远位置之间反复小步调整，直到两处都尽量重合。

观察标志：两个主光斑合成一个，移动观察屏距离时不再明显分裂。UCSB、NYU、Augusta University 和 Colorado Boulder 的教学资料均把返回光斑重合作为出现稳定干涉条纹前的关键步骤。

### 阶段三：扩束并调出可分析的激光条纹

1. 在不碰动干涉仪主体的前提下放入扩束镜、凹透镜或本装置规定的毛玻璃，使扩展光束同时覆盖两路返回光。
2. 调整扩束元件的横向位置和高度，使亮区居中；不要用动镜旋钮补偿扩束元件放偏造成的亮区偏移。
3. 适当降低环境光并调整相机曝光。亮纹不能大面积饱和，暗纹仍应保留层次；高增益造成的散斑噪声不能代替真实条纹对比度。
4. 若扩束后没有条纹，先撤回扩束元件复查两个主光斑是否仍然重合，再检查扩束元件是否使其中一路被截断。

观察标志：亮区内出现连续明暗条纹；轻微调节任一倾角旋钮时，整组条纹会同步移动或旋转。

### 阶段四：把动镜带到近等光程区域

1. 先根据装置尺寸把两臂几何长度调到接近；NYU 的实验说明把两臂距离先调到约 1 mm 量级的一致性，作为后续观察的粗起点。
2. 只使用动镜轴向微分机构缓慢改变臂长，不要把轴向微分机构与 A、B 倾角旋钮混淆。
3. 选定一个进给方向后尽量保持同向移动，以减少螺纹回程差。若必须反向，先越过空程再重新建立观察起点。
4. 按本项目已有流程，在条纹由圆环或明显弯曲逐渐接近直线、有效区域增大时，认为进入适合白光搜索的候选区。记录候选位置；不要因为激光仍能看到条纹就进行大范围连续扫描。

观察标志：条纹近似直线、能覆盖主要亮区，且轴向小步移动时条纹响应连续。这里只确定白光搜索的候选区，不宣称已经找到白光零光程差。

### 阶段五：用 A 把直条纹调成竖直

1. 站到动镜背面确认方向约定，先判断条纹需要在画面中顺时针还是逆时针旋转才能竖直。
2. 需要条纹顺时针旋转时，从动镜背面顺时针微调 A；需要条纹逆时针旋转时，逆时针微调 A。
3. 每次只转一个肉眼可控的极小角度，立即停手，等待条纹稳定后比较调整前后的倾角。A 对方向最敏感，不应连续快速转动。
4. 若倾角绝对值减小，可沿同方向再微调；若倾角增大，退回上一个较好位置并换方向。
5. A 的顺、逆时针实测都可能伴随条纹变密，因此方向调正后必须重新检查间距。

观察标志：条纹整体竖直；程序给出的 `tilt_deg` 接近 0，且方向置信度足够。若画面中存在青色中央辅助线，新算法会先抑制该辅助线再估计条纹方向，不能把辅助线本身当成干涉条纹。

### 阶段六：用 B 把条纹间距调到适中

1. 条纹过密、需要变宽时，从动镜背面顺时针微调 B。当前装置的实测响应是先快速变疏；接近最宽状态后若继续同向转动，条纹会再次变密，因此必须逐步观察。
2. 一旦间距不再增加或开始减小，说明越过了最宽点，应停止并小幅退回，不要假定 B 顺时针会使条纹一直变宽。
3. 条纹过疏、需要变密时，可从动镜背面逆时针微调 B。实测中条纹先有小角度逆时针转动，随后方向变化减弱而继续变密。
4. B 也会带动条纹旋转。间距合适后回到 A，小步修正方向；再用 B 复查粗细，形成 A—B—A 的闭环。

观察标志：有效视场中有数条清晰、可分辨的直条纹，间距足以稳定比较，且方向仍接近竖直。

### 阶段七：稳定性检查并切换白光

1. 停止所有调节，等待数秒，确认条纹没有由桌面振动、气流或镜架松动造成的持续漂移。迈克尔逊干涉仪对微小振动非常敏感。
2. 保存一帧原始激光条纹图，记录动镜轴向读数、A/B 当前状态、相机曝光和 ROI。程序间距质量门通过时再记录像素间距；未通过时只记录定性形态。
3. 切换光源前关闭激光，保持分束器、两块反射镜和 A/B 不动，再换上白光扩展光源。
4. 从已记录的动镜轴向位置附近开始，沿单一方向慢速寻找彩色条纹。出现彩色条纹后继续小步寻找中央黑色零级条纹；不要重新大幅转动 A/B，除非实时画面明确显示条纹方向或重合状态已经恶化。

## 5. 程序分析结果的使用方法

新版算法增加了任意方向激光直条纹处理：先估计全局条纹方向，抑制细青色显示辅助线；对于大角度或接近水平的条纹，先在内部校正到近竖直方向，提取二维中心线后再映射回原图。中心线角度采用正交拟合，因此接近水平时不再出现普通 `x(y)` 回归的奇点。

- `tilt_deg`：条纹相对竖直方向的角度，正值表示 `\` 形，负值表示 `/` 形；接近 ±90° 表示接近水平。
- `correction_deg`：只用于画面显示校正，等于 `-tilt_deg`；它不是应把物理旋钮转动多少度。
- `spacing_px`：相邻同类条纹中心沿条纹法向的像素距离，不是水平投影距离。
- `confidence` 和 `quality_valid`：算法质量判据，不是测量不确定度。只有 `quality_valid=true` 时才把间距用于前后定量比较。
- 有效条纹不足、间距波动大、运动模糊或只剩一条可见纹时，应保留定性判断，不得用程序跳动的像素值决定旋钮方向。

## 6. 常见现象与单步处理

| 现象 | 优先判断 | 当前只做的一步 | 预期变化与停止条件 |
|---|---|---|---|
| 完全没有条纹 | 两路主光斑未重合或一路被遮挡 | 撤下扩束元件，重新检查两个主光斑 | 两个主光斑在近、远屏位置都尽量重合 |
| 有两个分开的亮区 | 两束方向或位置未重合 | 只微调一个倾角旋钮，让主光斑靠近 | 光斑距离减小；若增大立即退回 |
| 条纹弯曲或呈圆环 | 尚未形成所需等厚直条纹，或近等光程候选区未找到 | 小步移动动镜轴向位置并观察曲率 | 条纹逐渐接近直线；无改善则返回上一个位置 |
| 直条纹明显倾斜 | 方向问题 | 按所需旋转方向微调 A | 倾角绝对值减小，接近 0 时停止 |
| 条纹太密 | 横向楔角过大或处在 B 的密集侧 | 顺时针小步调 B | 间距先增大；不再增大时立即停止或退回 |
| 条纹太疏 | 视场内条纹不足以稳定比较 | 逆时针小步调 B | 条纹逐渐变密；达到适中数量后停止 |
| 条纹方向正确但调粗细后又歪 | A、B 耦合 | 回到 A 做一次更小的方向修正 | 只纠正方向，不追求同时改变间距 |
| 程序显示约 ±90°但肉眼看不到连续条纹 | 光斑边界或残余辅助线可能主导方向估计 | 缩小 ROI 到清晰条纹区并改善曝光 | 至少两到四条连续纹出现后再相信方向/间距 |
| 停手后仍持续漂移 | 振动、气流、镜架或热漂移 | 暂停调节并隔离扰动 | 条纹稳定后再继续，不在漂移中记录 |

## 7. 实验助手的逐轮提问顺序

实验助手一次只推进一个问题，建议按以下顺序询问并等待确认：

1. 是否已经看到两路主要返回光斑？
2. 两个主光斑在近、远观察位置是否都重合？
3. 加入扩束元件后是否出现连续激光条纹？
4. 条纹现在是圆环、弯曲还是接近直线？
5. 直条纹需要顺时针还是逆时针旋转才能竖直？
6. 条纹目前过密、合适还是过疏？
7. 停手后是否稳定，程序质量门是否通过？
8. 是否已经记录动镜位置并准备关闭激光、切换白光？

任何一轮都采用“当前观察 → 一个小步动作 → 预期变化 → 停止条件”，不一次给出多个旋钮动作，也不声称已经替实验者完成硬件调节。
