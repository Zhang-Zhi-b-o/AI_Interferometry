## 第 2 页 · YOLO 如何"看懂"干涉条纹

**标题**：从"拍一张照片"到"找到零级条纹"

**布局**：左侧流程图 + 右侧原理图，底部一条实际效果对比

**左上——YOLO 原理（三步法，通俗解释）**：

```
📷 输入图像         ▦ 网格划分           🎯 同时预测            ✅ 筛选结果
┌─────────┐      ┌─────────┐        ┌─────────┐         ┌─────────┐
│ 相机拍摄  │  →   │ 切成 N×N │   →    │ 每个格子  │    →    │ 合并重叠  │
│ 干涉画面  │      │ 小格子   │        │ 预测框+   │         │ 保留最优  │
│         │      │         │        │ 类别     │         │         │
└─────────┘      └─────────┘        └─────────┘         └─────────┘
```

- **输入**：相机拍摄的干涉条纹画面
- **分格**：将图像划分为网格，每个格子独立检测条纹
- **同时预测**：每个格子一步完成"有没有条纹"和"是什么条纹"——不需先找再认
- **筛选**：从所有候选框中选出置信度最高的，去重合并

**右上——训练流程（小字，四步箭头环）**：

```
标注数据 → 模型学习 → 预测输出 → 与标注对比计算误差 → 调整参数 → 回到模型学习
```

**左下——本项目的检测目标**：

| 类别 | 画面特征 | 实验意义 |
|------|---------|---------|
| 零级条纹 | 零光程差处的黑条纹 | 实验终极目标 |
| 近场彩色条纹 | 零级附近的彩色条纹 | 搜索方向路标 |

**右下——实际效果对比**：
```
【图位】左侧：原始干涉条纹照片
【图位】右侧：同一张照片叠加 YOLO 检测框（黄色框=零级 0.92，蓝色框=近场 0.87）
```

**底栏——从 YOLO 框到精确中心**：

YOLO 检测框只告诉你"大概在这" → 在框周围扩大搜索 → 提取颜色剖面 → 多特征联合评分 → 亚像素精度定位 → 时序滤波防抖

**动画**：
- 左上四步从左到右逐个亮起（流水灯效果）
- 右上训练环持续转动 2 圈
- 左右对比图延迟 1s 后出现
- 底栏箭头流程从左到右生长

## 第 5 页 · 三系统协同 + 安全设计

**标题**：YOLO 是眼，大模型是脑——各司其职

**布局**：上半部分数据流图 + 下半部分左右分栏

**上半部分——全链路数据流**：

```
[干涉仪] → [USB相机1] → YOLO 实时分析 → 中心坐标 + 条纹方向
                                              ↓
                                    [自动控制状态机] → [步进电机] → 移动动镜
                                              ↓
[千分尺] → [USB相机2] → OCR 读数 ────────→ 实验阶段判定
                                              ↓
                                      只读状态快照(JSON)
                                              ↓
                                       [AI 实验助手] → 回答
```

用颜色区分：硬件灰 → 感知绿 → 控制橙 → AI 蓝。箭头带流动光点。

**左下方——为什么安全？**

| ✗ AI 不做的事 | ✓ AI 做的事 |
|-------------|-----------|
| 不控制电机 | 读取实验状态并给出建议 |
| 不编造读数/波长/误差 | 指出缺失数据，列出待补充项 |
| 不混淆置信度与不确定度 | 引用实时传感器数据 |

**右下方——为什么离线也能用？**

```
有网络 → DeepSeek API 在线生成
   │
   │ 网络中断
   ▼
无网络 → 本地 RAG 知识库 + 实时阶段规则 → 仍能给出操作指导
```

**动画**：
- 数据流从左上方开始，像流水一样沿箭头逐段点亮
- 最后 AI 助手节点放大发光
- 左下 ✗/✓ 行交替弹入
- 右下网络切换动画：绿色"在线"→ 过渡闪烁 → 灰色"离线"

**【图位】** 全链路数据流图（建议在 PPT 中手动绘制，方便分段动画控制）
