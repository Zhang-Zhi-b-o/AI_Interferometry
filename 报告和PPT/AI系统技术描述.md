# 迈克尔逊干涉仪智能辅助系统 — AI 技术描述

> 用途：项目报告与 PPT 制作的 AI 部分素材。

---

## 1. AI 系统总览

本项目的 AI 能力分为三层：

```
┌──────────────────────────────────────────────┐
│         AI 实验助手（大模型 + RAG）             │
│        接收只读状态 → 实验指导与报告生成          │
├──────────────────────────────────────────────┤
│         视觉 AI（YOLO 条纹识别）                │
│        实时检测 → 语义分类 → 中心定位            │
├──────────────────────────────────────────────┤
│         千分尺 OCR 读数                        │
│         LCD 定位 → 数字识别 → 稳定输出          │
└──────────────────────────────────────────────┘
```

三层之间通过只读状态快照连接：YOLO 和 OCR 提供感知数据，AI 助手消费数据、输出指导。AI 助手不直接控制硬件。

## 2. 核心原理

### 2.1 YOLO 目标检测

#### 什么是目标检测

目标检测要回答两个问题：图像中**哪里有物体**（用矩形框标出位置），以及**这些物体是什么**（给出类别标签）。例如，在一张干涉条纹照片中，检测算法需要框出每一组条纹并判断它是零级黑条纹还是近场彩色条纹。

#### YOLO 的基本思想

YOLO（You Only Look Once）的核心思路是**只看一次**。传统方法往往分两步走——先扫描图像找出可能包含物体的区域，再逐一判断每个区域是什么。YOLO 将这两个步骤合并：把整张图像一次性输入神经网络，直接输出所有物体的位置框和类别。

具体来说，YOLO 将输入图像划分为网格。每个网格单元负责预测以该单元为中心的一个或多个边界框，以及每个框属于各类别的概率。最终，网络同时输出成千上万个候选框，再通过非极大值抑制（NMS）筛选出最可靠的几个结果。整个过程只需一次前向传播，因此速度极快，适合实时视频处理。

#### 网络结构与训练

YOLO 的主干网络通常是一个卷积神经网络（CNN），负责从图像中提取多层特征：浅层检测边缘和纹理，中层识别形状和局部图案，深层理解语义——在我们的场景中就是"什么样的视觉模式构成一组干涉条纹"。

训练时需要大量标注好的图像：人工在每张图上画出干涉条纹的边界框并标注类别（零级条纹或近场彩色条纹）。模型通过反复比较自己的预测和人工标注之间的差异，逐步调整网络参数，最终学会在没有人工标注的新图像上准确识别条纹。

#### 本项目的应用

本项目使用 Ultralytics YOLO 框架，在自定义的干涉条纹数据集上训练模型，使其能够识别零级条纹（白光零光程差位置的黑条纹）和近场彩色条纹两类目标。检测结果为后续的中心精确定位和自动电机搜索提供位置先验。模型支持 GPU 加速推理，可在相机帧率下实时运行。

### 2.2 AI 实验助手工作流程

AI 实验助手的工作遵循检索增强生成（RAG）模式，流程如下：

1. **用户提问**：学生在界面中输入自然语言问题，可选择附带当前实验状态。

2. **知识检索**：系统从本地 Markdown 知识库中检索与问题最相关的文档片段。知识库包含实验原理、操作流程、故障诊断、不确定度评定和安全注意事项五类内容。

3. **状态快照构建**：系统收集当前时刻的相机状态、YOLO 检测结果、电机运行状态、千分尺读数和实验阶段判定，构建一个只读的 JSON 格式状态快照。

4. **提示词组装**：将系统提示词（定义助手角色、任务边界和安全约束）、历史对话、知识库检索结果、状态快照和用户问题组合为一次完整的请求。

5. **大模型生成**：请求发送至 DeepSeek API，模型以流式方式逐字生成回答，学生可实时看到输出。

6. **降级处理**：若 DeepSeek API 不可用（未配置密钥或网络故障），系统自动切换为离线模式，直接使用本地知识库检索结果和实验阶段信息生成回答。

整个流程在独立后台线程中执行，不阻塞界面交互，且支持中途取消。

### 2.3 千分尺 OCR

在干涉实验中，动镜位移通过数显千分尺读取。OCR 系统使用 PP-OCR 模型识别千分尺 LCD 屏幕上的数字，替代人工读数。原理上，这是一个经典的计算机视觉管线：定位 LCD 屏幕区域 → 图像增强使数字清晰 → 文本识别模型输出数字字符 → 多帧投票确保读数稳定。

## 3. 视觉 AI — YOLO 条纹识别

### 3.1 处理管线

```
相机帧 → YOLO 目标检测 → 中心条纹二次定位 → 运动方向判定
```

**YOLO 目标检测**：使用自定义训练的模型，实时检测画面中的零级条纹和近场彩色条纹，输出每个目标的边界框坐标和置信度。

**中心条纹精确定位**：YOLO 的检测框提供"条纹大概在哪"的初步判断。由于检测框的几何中心不一定是物理的零光程差位置，系统在框周围扩大搜索区域，提取横向颜色剖面、计算条纹的相干包络，通过多特征联合评分确定亚像素级的中心坐标。定位结果经过时序滤波处理，抑制跳动和短时丢帧。

**运动跟踪**：在连续帧中追踪条纹位置变化，判断条纹的移动方向（左移/右移/稳定）。这一信息直接用于自动搜索中电机方向的决策。

### 3.2 与传统图像处理的区别

传统图像处理方法需要人工设计特征（如条纹间距、灰度阈值），对光照变化和噪声敏感，适应性差。YOLO 通过大量标注数据自动学习干涉条纹的视觉模式，在不同亮度、模糊程度和条纹密度下都能保持稳定的识别能力。

## 4. AI 实验助手

### 4.1 功能定位

基于大语言模型的实验辅助系统，覆盖预习、操作指导、条纹诊断、误差计算和报告生成五个环节。

### 4.2 系统架构

```
用户提问
   │
   ▼
┌─────────────────────────────────┐
│         AgentService            │
│                                 │
│  ┌───────────┐  ┌────────────┐  │
│  │ 本地知识库 │  │ DeepSeek    │  │
│  │ (RAG)     │  │ 大模型      │  │
│  └─────┬─────┘  └─────┬──────┘  │
│        │              │         │
│  ┌─────▼──────────────▼──────┐  │
│  │   实时实验状态快照（只读）   │  │
│  └───────────────────────────┘  │
└─────────────────────────────────┘
   │
   ▼
格式化输出（Markdown / LaTeX 公式）
```

### 4.3 核心组件

**本地知识库**：5 篇 Markdown 文档覆盖实验原理、操作流程、故障诊断、不确定度评定和 AI 安全边界。使用关键词检索，不依赖外部向量数据库。

**大模型调用**：使用 DeepSeek Chat Completions API，流式输出，支持中途取消。系统提示词规定任务范围和安全约束：不编造实验数据、不混淆模型置信度与测量不确定度、传感器数据与知识库冲突时以传感器为准。

**实时状态感知**：每次提问时将相机、YOLO、电机、千分尺和实验阶段的当前状态注入请求，使模型回答基于现场实际情况。

**离线降级**：DeepSeek 不可用时，以本地知识库检索结果和实验阶段信息组合生成回答，无需网络连接。

---

## 5. 千分尺 OCR 读数

使用 PP-OCRv6 ONNX 模型本地推理，驱动第二路 USB 摄像头拍摄数显千分尺 LCD 屏幕。系统自动定位 LCD 区域并识别数字，经多帧投票稳定化输出。

                              ↓

                              ↓

                              ↓
