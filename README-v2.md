# 白光干涉测量工作台 v2

`run.py` 默认启动本版本（旧 Tkinter 版仍可从 `src.ui.run_app` 启动，仅作回退）。
完整离线演示及电机连接入口已可用，真实设备效果仍待走查。

1. 在项目目录安装：`python -m pip install -e ".[v2]"`。
2. 启动：`python run.py`；安装后也可运行 `michelson-v2`。
3. 在搜索页顶部填 `auto` 或 `COM3` 等串口号，选择波特率（通常 9600）并连接；再打开相机、加载模型，进入搜索、读数和计算流程。

模型权重和 OCR 模型需另行放在项目约定目录，不包含在 wheel 中。模型可在实时页选择路径。
助手沿用 `DEEPSEEK_API_KEY` 或本地 `config/secrets.yaml`，无密钥时提供本地建议。
详细配置与功能边界见 [app/README.md](app/README.md)。

- 在主窗口按 Esc 或点击顶栏“停止运动”，停止闭环、取消助手和未完成的连接请求。
- 搜索页点击“断开”，先停止寻中与目标读数，再在后台停车关闭串口；连接成功本身不会启动电机。
  驱动已经阻塞的 I/O 需待其返回后完成停车，界面保持可响应。
- 厚度分布页分析后点击“查看 3D 形貌”，可旋转、缩放及保存当前视角 PNG。
  无效区域留空；X/Y 为分析区域的像素坐标，Z 单位为 μm。
  未设置独立厚度锚点时表示相对起伏，不能据此报告绝对厚度。
- 搜索方向与电机映射须先在真机核对；已搜索范围是转速积分估计。

无相机时可运行 `python run_v2.py --image "图片路径.png" --page map`，
分析图片并查看 3D；中文路径可用。静态图片不会用于驱动电机。
完整离线演示：`python run_v2.py --demo`（与 `--image` 互斥）。
虚拟相机、电机、微分表和检测已就绪，无需权重、设备或 API Key。
助手强制离线；界面持续标记演示，导出 CSV/JSON/报告含演示来源，默认保存在 `exports/demo/`。
模拟检测/条纹指标使用已知合成参数，不代表真实模型或测量准确度。

建议演示顺序：

1. 在计算页点击“把当前读数填入 d₁”（初值约 0.9800 mm）。
2. 去搜索页点击“开始自动寻中”，等待停在画面中心。
3. 回到计算页填入当前 d₂，计算、加入多轮并导出。仅一轮时样本标准差显示为不足两轮。
4. 搜索页切换目标读数，输入 1.005 mm；读数页可记录虚拟读数。
5. 条纹页测量；厚度分布页分析合成画面并打开 3D；助手页可查看离线建议。

演示微分表范围为 0.9–1.1 mm，建议目标取 1.000–1.010 mm。所有演示动作只改变内存状态。
截图自检：`python run_v2.py --page map --screenshot exports/v2-map.png`。
