## 二、线性回归

使用全部 25 个数据点（5 mm × 5 组）做最小二乘拟合：

```
mm = slope × native_px + intercept
```

| 参数 | 值 |
|------|------|
| **斜率** | −0.000444 |
| **比例 (mm/px)** | **0.000444** |
| **截距** | 1.1070 mm |
| **R²** | **0.9924** |
| **1mm ≈** | 2251 px（原生） |

## 三、结论

- 线性关系良好（R² = 0.9924），像素位移与千分尺移动严格成正比
- 比例系数：**每 1 个原生像素对应千分尺移动 0.000444 mm**
- 即千分尺移动 **0.01 mm ≈ 22.5 原生像素**
