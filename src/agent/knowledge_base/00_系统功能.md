## 系统是什么

这是一套迈克尔逊白光干涉实验的智能辅助系统。用 USB 相机采集干涉图像，用双类别
YOLOv8 模型识别零级条纹和近场条纹，在检测框内进一步定位中心条纹，并通过 RS-232
控制步进电机完成自动搜索和闭环寻中。第二台相机读取数显微分表。系统还提供视频录制、
玻璃片厚度多轮测量与统计、临时位移控制、回程差测量、中心条纹宽度分析、实时测量记录，
以及可自主执行工具的「实验助手」智能体和可在终端独立运行的 `michelson` 命令行。

## 主要能力

- 干涉相机实时预览、旋转、缩放、平移、ROI 和视频录制；
- YOLO 实时检测零级条纹与近场条纹，并在零级框扩展区域内定位实际中心条纹（不把框中心
  直接当结果）；短时漏检时继续视觉跟踪中心，识别倾斜、弯曲、变色和低对比度条纹；
- 根据连续位置估计条纹移动方向、位移和速度，运动模糊时自动降速；
- 控制步进电机自动搜索、闭环寻中（把零级中心黑条纹移到画面水平中央）；
- 第二台相机 + 本地 PP-OCR 读微分表；
- 玻璃片厚度多轮测量与统计、目标读数控制、回程差测量、中心条纹宽度分析、实时测量记录；
- 单张彩色干涉图的薄膜厚度分布分析（相对模式，或经颜色→光程差标定的标定模式）；
- 实验助手：逐轮互动引导，或自主执行智能体（自定计划、调用工具，运动需人工确认）；
- 无操作一段时间后给出 DeepSeek 主动建议（现状 + 下一步 + 其他建议）；
- `michelson` 命令行：纯逻辑子命令（算厚度、评不确定度、析条纹宽度、估厚度分布、寻中状态机）可脱离 GUI 运行。

## 界面五大模块

- 01 视觉观察：实时状态、摄像头、模型与预测、中心条纹分析、视频录制；
- 02 运动控制：电机连接、手动命令、自动寻中组合；
- 03 测量记录：视觉微分表读数、玻璃片厚度测量、多轮测量与统计；
- 04 实验助手：AI 助手浮窗（自主执行 + 互动问答 + 主动建议）与运行日志；
- 05 临时测量：目标读数控制、回程差测量、中心条纹宽度测量、实时测量与记录、颜色→光程差标定采集。

## 关键测量与公式

- 玻璃片厚度：`h = (d2 − d1) / [20 × (n − 1)]`，`d1`、`d2` 为两次中心条纹出现时的
  微分表读数（mm），`n` 为玻璃折射率（默认 1.4586）。
- 中心条纹宽度：取横向亮度剖面、估计条纹周期、切分明暗条纹，给出中心条纹宽度与周期。
- 薄膜厚度分布：相对模式 `Δt = λ / (2(n−1))`（一个颜色周期对应一个有效干涉级次，
  默认折射率 1.523）；标定模式 `t = opd_um / (n−1)`（opd_um 为动镜位移 μm），
  需要颜色→光程差标定表。

## 安全与真实性约定

- 助手只读工具自动执行；使电机转动的工具必须先经界面人工确认；停止工具始终放行。
- 智能体只编排高层操作，不逐拍驱动电机，底层 PID / 寻中 / 停车由 GUI 实时循环安全执行。
- 数值（读数、厚度、误差、不确定度）以程序确定性计算和工具结果为准，助手不得编造。
