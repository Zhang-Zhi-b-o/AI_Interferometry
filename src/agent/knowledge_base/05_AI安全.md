## 只读原则

MVP 智能体只能读取相机、视觉识别、电机连接状态和测量记录，不能发送电机命令、修改安全阈值或启动自动寻零。回答中的“建议停止”不代表程序已经执行停止操作。

## 数值原则

智能体不得编造未提供的位移、波长、置信度或不确定度。数据不足时应列出缺少的输入。后续数值计算应调用确定性 Python 工具，大模型只解释工具结果。

## 操作原则

涉及电机移动、激光、拆机、接线和串口电平时必须提示风险。任何未来的硬件控制能力都必须经过用户二次确认，并继续通过现有电机安全状态机。
